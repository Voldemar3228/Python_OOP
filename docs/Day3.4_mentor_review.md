# Ревью ментора
Есть пару замечаний
* Неверный возврат баланса клиента: ветка **gettotalbalance** для конкретного клиента всегда возвращает 0, потому что там возвращается переменная summa, а не результат **getbalance**. Внешние вызовы получают неверные данные и не могут строить аналитику по клиентам. (src/main.py:819–832)
* Модуль блокирует импорт из-за автоматического сценария: тестовый код выполняется на уровне модуля без if name == "main":, сразу создаёт банк и вызывает transaction, что моментально уходит в authenticateclient с input() и блокирует процесс при любом import src. Это делает невозможным повторное использование классов и автоматическое тестирование. (src/main.py:763–1054)
