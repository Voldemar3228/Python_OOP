    * в методах зачисления и снятия средств добавлена проверка на подозрительную активность и запрет проведения операций.

    * в методе **deposit** был поправлен баг с нулевым минимальном остатком при создании счета с помощью флага **first_operation**.

## class Bank

### Справочная информация
1. Для того, чтобы выполнить любую операцию со счетом, необходимо соотнести счет и клиента, к которому привязан этот счет.
2. В системе банка отсутствуют счета, которые ни к кому не прикреплены. У каждого счета есть владелец(клиент).

### Блок статических переменных
Предназначен для редактирования параметров класса **Bank**. 

**CLIENT_DB** - список карточек клиентов (экземпляров класса **Bank_Client_card**).

**ACCOUNT_DB** - список счетов (экземпляров классов из **ACCOUNT_TYPE**) всех клиентов.

**CURR_CLIENT** - текущая карточка клиента (экземпляр класса **Bank_Client_card**), под ним выполняются операции со счетами, которые ему принадлежат.

**ACCOUNT_TYPE** - словарь доступных счетов. С его помощью удобно будет в дальнейшем добавлять и удалять новые счета.

**OVERDRAFT_TOTAL** - лимит использования заемных средств. Только для типа счета 'InvestmentAccount'.

**OVERDRAFT_DAILY** - слимит использования заемных средств в день. Только для типа счета 'InvestmentAccount'. Пока не используется в проекте.

**PERCENT_RATE** - процентная ставка. Используется при создании счетов типа 'SavingsAccount' и 'InvestmentAccount'.

### Атрибуты
    name                 название Банка

### Методы

**def add_client(self, add_full_name, add_client_id, add_contact_info, add_birthday, add_password)**
1. Принимает на вход ФИО, id клиента, контакты, дату рождения и пароль.
2. Если "id клиента" уже существует в банковской системе клиентов (**CLIENT_DB**), ему генерипуется новый уникальный id.
3. Карточка нового клиента добавляется в базу клиентов **CLIENT_DB**.
4. Карточка нового клиента становится "текущей": она записывается в **CURR_CLIENT**.

**def open_account(self, add_account: str, add_acc_id, linked_person_id, add_currency)**
1. Принимает на вход тип создаваемого счета, id счета, id клиента, к которому будет привязан счет, валюту.
2. Нельзя создать счет, которого нет в **ACCOUNT_TYPE**.
3. Нельзя создать счет, если клиента нет в банковской системе клиентов(**CLIENT_DB**).
4. Если "id счета" уже существует в банковской системе счетов (**ACCOUNT_DB**), ему генерипуется новый уникальный id.
5. Новый счет добавляется в карточку клиента.
6. Новый счет добавляется в базу счетов **ACCOUNT_DB**.

**def close_account(self, close_id)**
1. Принимает на вход id счета.
2. Меняет статус счета на 'закрытый'. С этого момента поменять статус счета нельзя.

**def freeze_account(self, freeze_id)**
1. Принимает на вход id счета.
2. Ищет в банковской системе счетов (**ACCOUNT_DB**) нужный счет и меняет статус на 'замороженный'.
3. Ищет клиента в **CLIENT_DB**, к которому привязан этот счет, находит этот счет в списке его счетов (**accounts**) и меняет статус найденного счета на 'замороженный'.

**def unfreeze_account(self, frozen_id)**
1. Принимает на вход id счета.
2. Ищет в банковской системе счетов (**ACCOUNT_DB**) нужный счет и меняет статус на 'активный'.
3. Ищет клиента в **CLIENT_DB**, к которому привязан этот счет, находит этот счет в списке его счетов (**accounts**) и меняет статус найденного счета на 'активный'.

**def close_account(self, close_id)** (был добавлен для тестирования операций со счетами)
1. Принимает на вход id клиента.
2. Ищет в банковской системе клиентов (**CLIENT_DB**) нужного клиента и меняет его статус на 'закрытый'. С этого момента поменять статус клиента нельзя.

**def freeze_client(self, freeze_id)** (был добавлен для тестирования операций со счетами)
1. Принимает на вход id клиента.
2. Ищет в банковской системе клиентов (**CLIENT_DB**) нужного клиента и меняет его статус на 'замороженный'.

**def unfreeze_account(self, frozen_id)** (был добавлен для тестирования операций со счетами)
1. Принимает на вход id клиента.
2. Ищет в банковской системе клиентов (**CLIENT_DB**) нужного клиента и меняет его статус на 'активный'.

**def authenticate_client(self, name)**
1. Принимает на вход id клиента.
2. Ищет в банковской системе клиентов (**CLIENT_DB**) нужного карточку клиента и достает его пароль.
3. Путем ввода через терминал осуществляется 3 попытки аутентификации:
    * если введенный пароль совпадает с паролем клиента, карточке клиента присваивается статус "текущий" (она записывается в **CURR_CLIENT**).
    * если за все попытки пароли не совпали, то статус клиента меняется на 'замороженный'.

**def search_accounts(self, account_id)**
1. Принимает на вход id счета.
2. Ищет в банковской системе счетов (**ACCOUNT_DB**) нужный счет и выводит ему информацию о счете.

**def show_all_clients(self)** (был добавлен для удобства)

Выводит информацию всех клиентов банковской системы и их флаги подозрительных действий.

**get_balance(self, client_id)**
1. Принимает на вход id клиента.
2. Рассчитывает и возвращает баланс всех счетов клиента.

**get_total_balance(self, client_id:str = None)**
1. Если на вход не подается ни одного атрибута, вызывается метод **get_balance** для подсчета и суммирования балансов всех клиентов банковской системы.
2. Если на вход подается id клиента, то вызывается метод **get_balance** для вывода баланса клиента.

**get_clients_ranking(self)**
1. Составляется словарь "Карточка клиента" -> "Суммарный баланс счетов" с использованием метода **get_balance** .
2. Сортируется словарь по балансу от богатых к бедным и выводится пользователю на экран.

**transaction(self, *args)**
1. Принимает на вход:
    * id счета,
    * тип операции (любой метод из доступных счетов), 
    * ценную бумагу (необязательно),
    * сумму (необязательно).
2. Ищет в карточке текущего клиента **CURR_CLIENT** нужный счет:
    * если находит, то выполняется метод выбранного счета (далее - транзакция).
    * если не находит, то в банковской системе клиентов (**CLIENT_DB**) ищется тот клиент, у которого есть нужный счет. Если такой находится, он должен осуществить авторизацию **def authenticate_client**. После успешной авторизации выполняется транзакция.
    * вывод: транзакция всегда выполняется под текущим клиентом.
3. Каждая транзакция, выполняющая какие-либо операции со счетом:
    * возвращает **True** в случае ее успешного завершения.
    * возвращает **False** в случае ее провала (из-за ошибки, исключения, валидации и т.д.).
4. Если транзакция вернула **False**, текущему клиенту ставится флаг подозрительных действий равный **True**.

**def __str__(self)**

Выводит информацию о Банке: его имя, клиентов и созданные ими счета.
