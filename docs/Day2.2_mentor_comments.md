# Ответы на вопросы от ментора
## SavingsAccount

**min_balance**
Да, это минимальный остаток за период. После каждой операции можешь делать:
min_balance = min(min_balance, balance).

**месячная ставка доходности**
Да, просто атрибут, например monthly_rate = 0.02 (2% в месяц).

**apply_monthly_interest()**
Твоя идея норм:

берём min_balance (или текущий balance, как решишь),

считаем проценты: interest = min_balance * monthly_rate,

прибавляем к балансу,

обновляем min_balance до текущего balance.

## PremiumAccount

**увеличенные лимиты**
Сделай атрибуты типа:

overdraft_limit — сколько можно уйти в минус,

опционально daily_withdraw_limit — максимум снятия в день.

**овердрафт**
Да, возможность уйти в минус до -overdraft_limit.
В withdraw сначала списываешь из обычного баланса, если не хватает — допускаешь минус, но не ниже -overdraft_limit.

**фиксированная комиссия**
Проще всего: атрибут fee, который добавляется к каждому снятию.
То есть снимаем amount + fee. Долг/проценты можно не усложнять.

## InvestmentAccount

**инвестиционные портфели**
Сделай, например, portfolio: dict, типа
{"stocks": 5000, "bonds": 2000, "etf": 3000} — просто разбиение баланса по типам активов.

**виртуальные активы**
Может быть строковый атрибут с одним из значений "stocks" | "bonds" | "etf".
Да, можно добавить простую валидацию в init.

**project_yearly_growth()**
Метод, который считает прогноз баланса через год:
return balance * (1 + expected_return)
где expected_return, например, 0.1 (10% в год).
Хочешь — можешь учесть разные проценты для разных типов активов в portfolio.

## Дополнение
Базовый / SavingsAccount: обычное снятие без ухода в минус + обновление min_balance.

PremiumAccount: снимаешь amount + fee, разрешаешь минус до -overdraft_limit.

InvestmentAccount: можно, например, разрешить снимать не более X% баланса или брать отдельную комиссию за вывод — главное, чтобы поведение отличалось от базового.

get_account_info() vs str

get_account_info() — «служебный» метод, возвращает данные (dict/строку) для логики и тестов.

__str__() — красивый текст для print(account). Часто внутри он просто использует get_account_info() и форматирует.
